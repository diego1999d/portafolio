# Predicción de cancelación de clientes (Churn)

## 📌 Contexto del negocio
La cancelación de clientes representa uno de los principales retos para las empresas de telecomunicaciones, ya que impacta directamente en los ingresos y la estabilidad del negocio.

El objetivo de este proyecto es **identificar clientes con alta probabilidad de cancelar el servicio**, permitiendo a la empresa tomar acciones preventivas de retención.

---

## 🎯 Objetivo
Construir un modelo de **machine learning** que prediga el churn de clientes utilizando información:
- Contractual
- Demográfica
- De servicios contratados

---

## 📂 Datos utilizados
Los datos provienen de 4 fuentes principales:
- `contract.csv`
- `personal.csv`
- `internet.csv`
- `phone.csv`

> ⚠️ Los datasets no se incluyen en el repositorio por buenas prácticas.

---

## 🧪 Metodología
El proyecto se divide en tres etapas:

1. **Preparación de datos**
   - Limpieza
   - Unificación de fuentes
   - Ingeniería de variables

2. **Modelado y evaluación**
   - Modelos de clasificación
   - Comparación de métricas
   - Selección del mejor modelo

3. **Conclusiones y recomendaciones**
   - Resultados finales
   - Impacto en el negocio
   - Recomendaciones estratégicas

---

## 📊 Resultados clave
- Se logró identificar clientes con alta probabilidad de churn
- El modelo final ofrece una herramienta útil para estrategias de retención
- Las variables más relevantes están relacionadas con el tipo de contrato y servicios activos
