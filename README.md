# Portafolio de proyectos — Diego Durán

Este repositorio reúne los principales proyectos realizados durante mi formación en análisis de datos.  
Cada carpeta corresponde a un proyecto independiente con su propio `README.md`, `requirements.txt` y archivos de trabajo (datasets y notebooks).

---

## 📁 Proyectos

### 🧩 Proyecto 1 — Análisis de comportamiento de clientes
**Objetivo:** estudiar patrones de compra y segmentar usuarios con base en su comportamiento.

### 📊 Proyecto 2 — Estudio de planes de telecomunicaciones (Megaline)
**Objetivo:** determinar qué tarifa de prepago genera más ingresos para la empresa a partir del análisis de datos de llamadas, mensajes e internet.

### 🚕 Proyecto 3 — Análisis de viajes en Chicago (Zuber)
**Objetivo:** identificar patrones de demanda y factores que afectan la duración y frecuencia de los viajes.

### 🛒 Proyecto 4 — Análisis de pedidos en Instacart
**Objetivo:** analizar datos de pedidos de supermercado para identificar tendencias de compra y optimizar recomendaciones de productos.

### ⚙️ Proyecto 5 — Recuperación de oro (Gold Recovery)
**Objetivo:** construir un modelo para predecir la eficiencia de recuperación en una planta metalúrgica y ayudar a optimizar el proceso de producción.

🧠 Proyecto 6 — Predicción de cancelación de clientes (Churn)

Objetivo: construir un modelo de machine learning para identificar clientes con alta probabilidad de cancelar el servicio
en una empresa de telecomunicaciones, con el fin de apoyar estrategias de retención.
